# Security policy

This is experimental firmware extension software for legacy hardware, without
warranty or a guaranteed security-response schedule. Read [security limits](docs/security.md).
Keep printers on a trusted isolated LAN. Do not publish backups, credentials,
private keys, real registration/serial data or crash dumps in issues.

Report a reproducible issue with the exact profile, source revision, affected
component and sanitized steps. For credential-bearing evidence, arrange a
private channel with the maintainer rather than attaching it publicly.

The project does not claim that hidden cloud menus secure the device, that all
firmware vulnerabilities are fixed, or that route blocking replaces a router
firewall. Supported profiles and validation status are explicit in the docs.
