# Bootsplash artwork

`revival-v3-flat.png` is the approved project artwork, generated/recomposited
during development and used by the native header wordmark as well as the splash.
It contains no printer identity or credentials. The original display orientation
is 480×320 landscape; kernel/framebuffer conversion is 320×480 RGB565/indexed.

The logo was corrected against flat logo references rather than relying on a
generated approximation. Geometry source:
https://github.com/simple-icons/simple-icons/blob/develop/icons/flashforge.svg

Official visual reference/media kit:
https://www.flashforge.com/pages/press

Blue/orange recoloring and dark project layout are project-specific. The
“Revival Project” lettering is baked into this artwork, not a distributed font.
The touchscreen crops that same lettering instead of guessing a matching font.
Flashforge branding identifies original hardware; the project is independent.
